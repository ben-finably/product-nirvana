## Structure

```
product-nirvana/
├── index.html            ← series hub (lists every deck)
├── series-01/
│   └── index.html        ← first presentation
└── series-02/            ← next deck goes here
    └── index.html
```

Each deck is a single self-contained HTML5 canvas file (1920×1080).
Controls: → / Space / click right = next · ← / click left = previous · F = fullscreen · R = restart.
Add `#N` to a deck URL to open scene N directly.
