# Rules for this repository

- Files under `masters/` are master presentations with the author's hand-made design. Never modify, regenerate,
  restyle or replace them unless the author explicitly asks to change that specific master.
- `series-02/slides/*.webp` are exact renders of `masters/series-02/10X-Agile-finably_V3.pptx`. Only re-render them
  from the master (LibreOffice → PDF → 1920×1080 images); never edit or redesign them.
- New decks follow the Finably brand: Raleway, the finably logo (vector), purple #BA00FF / blue #0A50FF with the
  after-style vivid accents (amber #FFB23F, orange #FF6B2C), dark/light alternation.
- Each new deck lives in its own `series-XX/` folder, and the hub (`index.html`, `SERIES` array) gets a card for it.
